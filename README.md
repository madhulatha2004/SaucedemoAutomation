# SauceDemo Automation Project
This project is for testing the SauceDemo website using Python, Selenium, and Pytest. It checks if the main features of the website are working correctly or not, like logging in, sorting products, adding to cart, checking out, and logging ouut.

# Features
- Login to the website
- Sort products by different options
- Add specific products to the cart
- Check if products are correctly added to the cart
- Complete the checkout products
- Logout from the website

# Tools Used
- Python
- Selenium
- Pytest

# Fixtures
Fixtures help set up things before tests run like opening the browser. They are defined in the conftest.py file
